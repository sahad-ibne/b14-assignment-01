# DevConf 2026 Landing Page 🚀

DevConf 2026 is a responsive developer conference landing page designed to showcase event details, keynote speakers, pricing plans, and an interactive career fair section.

---

## 📌 Project Overview
This project mainly assigned by Programming Hero. It includes structured sections for speaker announcements, ticket purchasing plans, on-site career fair listings, and social links.

## 🛠️ Main Technologies Used
* **HTML5:** Semantic markup (`<nav>`, `<header>`, `<main>`, `<section>`, `<footer>`)
* **CSS3:** Custom styling and responsive layout designs (`style.css`)
* **Font Awesome:** Scalable vector icons for social media integration

---

## ✨ Key Features
* **Navigation & Hero Header:** Clear navigation bar and high-impact hero banner with call-to-action registration.
* **Featured Speakers Section:** Grid showcasing prominent keynote speakers across AI/ML, Cloud, Frontend, and Security.
* **Pricing Tiers:** Multi-level ticket options (Standard, Pro, Team) with detailed benefit lists.
* **Career Fair Listing:** Live job board section featuring open roles and venue booth details for hiring partners.
* **Responsive Footer:** Integrated social icons and copyright branding.
